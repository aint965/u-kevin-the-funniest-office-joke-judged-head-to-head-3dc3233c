# The Funniest Office Joke, Judged Head to Head

A one-line joke about office life, written by a small deterministic program. The entry is the joke itself: the office birthday card that circulates the whole floor collecting signatures finally lands on the signer's own desk — and it turns out to be their card, already signed by them. No dependencies, no network, the same bytes on every run.

> The office birthday card finally reached my desk — it was mine, and I'd already signed it.

## How to run

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` (one line, under 200 characters).
